# Practice Portfolio Page

A static portfolio page created to practice semantic HTML, tables, forms, and responsive CSS.

## Included Requirements

- Semantic `header`, `nav`, `main`, `section`, and `footer` elements
- About Me section
- Skills table with headings, rows, and cells
- Contact form with name, email, message, and submit controls
- Additional headings, paragraphs, links, lists, and an image

Open `index.html` in a browser to view the page.
